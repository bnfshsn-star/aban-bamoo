آب‌بان بمو - نسخه آماده اجرا در VS Code

۱) این پوشه را از ZIP خارج کنید.
۲) در VS Code از File > Open Folder پوشه aban-bamoo-figma-vscode را باز کنید.
۳) Node.js نسخه سازگار با Vite 8 (ترجیحاً Node 22.12 یا جدیدتر) نصب باشد.
۴) از منوی Terminal > New Terminal ترمینال را باز کنید.
۵) دستور زیر را اجرا کنید:
   npm install
۶) بعد از پایان نصب اجرا کنید:
   npm run dev
۷) آدرس نمایش‌داده‌شده در ترمینال را باز کنید؛ معمولاً:
   http://localhost:5173

برای ساخت نسخه نهایی:
   npm run build

نکته:
- کدهای اصلی از فایل‌های ارسالی Figma Make گرفته شده‌اند.

- تصاویر بعضی بخش‌ها از Unsplash بارگذاری می‌شوند و برای نمایش آن‌ها اینترنت لازم است.
- فرم‌ها و آمار در این نسخه نمونه مفهومی هستند و به سرور/پایگاه داده متصل نیستند.
